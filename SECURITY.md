# Security Policy

**English** · [简体中文](./SECURITY.zh-CN.md)

AI4Math Chronicle is a static website and public data archive. Security reports should focus on vulnerabilities or privacy-sensitive problems in the repository, build/deployment workflow, public site, or project-owned assets.

## Reporting a vulnerability

Please do **not** publish credentials, private data, exploit details, or a working proof of concept in a public Issue.

If the repository's **Security** tab offers **Report a vulnerability**, use that private reporting channel. If private vulnerability reporting is not available, open a minimal public Issue stating that you need a private channel to report a security-sensitive problem, without including sensitive details.

For ordinary rendering bugs, broken links, factual corrections, or editorial disputes, use the repository's structured Issue forms instead.

## Supported version

The supported version is the current `main` branch and the production GitHub Pages deployment derived from it.

## Scope notes

Third-party papers, websites, repositories, models, datasets, and artifacts linked by the Chronicle are outside this project's security boundary. Please report vulnerabilities in those systems to their respective maintainers.
